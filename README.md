# VBA Coach

Application personnelle d'entraînement (contenu chiffré — un code est nécessaire pour l'ouvrir).

## Mise en ligne (GitHub Pages)

1. Sur github.com : **+ → New repository**, nom `vba-coach`, **Public**, puis **Create repository**.
2. Clique **uploading an existing file**, glisse **tous les fichiers** de ce dossier
   (`index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `README.md`),
   puis **Commit changes**.
3. **Settings → Pages** → Source : **Deploy from a branch** → branche **main**, dossier **/ (root)** → **Save**.
4. Attendre 1 à 2 minutes : l'app est à l'adresse `https://<ton-pseudo>.github.io/vba-coach/`
   (l'adresse exacte s'affiche en haut de la page Settings → Pages).

## Installer l'app

- **iPhone** : ouvrir l'adresse dans **Safari** → bouton **Partager** → **Sur l'écran d'accueil**.
- **Android** : ouvrir l'adresse dans **Chrome** → menu **⋮** → **Installer l'application** (ou « Ajouter à l'écran d'accueil »).
- **PC** : ouvrir l'adresse dans **Chrome** ou **Edge** → icône **Installer** à droite de la barre d'adresse.

Au premier lancement, entrer le code personnel et laisser cochée « Se souvenir de moi sur cet appareil ».
Ensuite l'app fonctionne **même sans Internet**.

## Mettre à jour

Déposer les nouveaux fichiers au même endroit (Add file → Upload files → Commit changes).
L'app se met à jour au lancement suivant avec Internet (si besoin : fermer complètement l'app et la rouvrir).

## Progression

La progression est enregistrée sur chaque appareil. Pour la transférer : Accueil → **Exporter ma progression**,
puis sur l'autre appareil : Accueil → **Importer un code**. Exporter régulièrement sert aussi de sauvegarde.
